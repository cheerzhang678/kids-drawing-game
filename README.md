# 小小画家 🎨

一个面向儿童的浏览器画画小游戏，纯前端单文件实现（HTML + CSS + Canvas）。

## 功能

- **三种模式**：画笔、贴纸、橡皮
- **14 种颜色**，包括湖绿、深绿等专门色
- **3 档笔刷粗细**
- **贴纸**：动物 + 植物 emoji
- **画纸背景**：20+ 种可选背景，包括
  - 渐变类：天空、草地、晚霞、黄花、香水、石头、蓝莓、椅子、红砖、斑马、雪冰、小麦、深夜
  - 图案/图形类（默认收在「更多…」里）：白纸、方格、大海、拱门、阁楼、树木、波兰、月夜、星空、小桶等
- **撤销 / 清空 / 保存 / 下载 PNG**
- **自动快照**：每 30 秒本地存档，支持恢复
- 支持鼠标和触屏

## 使用

直接用浏览器打开 `index.html` 即可，无外部依赖。
